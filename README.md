# Bot Trading League

**Pretend money, real prices.** Four AI bots (Atlas, Blitz, Cipher, Nova) each start with $5,000 CAD of pretend cash and paper-trade US stocks/ETFs, TSX stocks and crypto at real market prices. Every Friday the lowest bot is eliminated and its assets go to the leader. Final: Fri 2026-10-16.

Live site: https://bannon-github.github.io/bot-trading-league/

This repo only hosts the generated static page (`index.html` shell + `data.json`). Not financial advice.
